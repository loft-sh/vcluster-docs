The `integrations` key configures integrations with tools on the control plane cluster, such as cert-manager, External Secrets Operator, Istio, KubeVirt, the control plane cluster's metrics server, Netris, and Argo CD. For setup guides, see the integration pages, such as [External Secrets Operator](../../integrations/identity-secrets/external-secrets-operator.mdx) and [Istio](../../integrations/networking/istio.mdx).
