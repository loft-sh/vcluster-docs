By default, this is disabled.

Sync [VolumeSnapshotClass](https://kubernetes.io/docs/concepts/storage/volume-snapshots/#volumesnapshotclasses) resources from the control plane cluster to the tenant cluster. A VolumeSnapshotClass tells a CSI driver how to take a snapshot, similar to how a StorageClass tells it how to provision a volume. A [VolumeSnapshot](../to-host/storage/volume-snapshots.mdx) created in the tenant cluster normally references a VolumeSnapshotClass by name. Sync the classes that exist in the control plane cluster before enabling VolumeSnapshot syncing.

### Sync VolumeSnapshotClasses from the control plane cluster to the tenant cluster

```YAML
sync:
  fromHost:
    volumeSnapshotClasses:
      enabled: true
```

## Patches

Use `sync.fromHost.volumeSnapshotClasses.patches` to transform VolumeSnapshotClass fields while syncing to the tenant cluster. See [Patching synced resources](../patching/README.mdx) for syntax, directionality, and examples.
