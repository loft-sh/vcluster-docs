---
title: vCluster Labs egress IP addresses
sidebar_label: Egress IP addresses
description: Public IPv4 addresses that vCluster Labs uses for outbound connections to customer infrastructure, for firewall allowlists.
---

Connections that vCluster Labs makes to your infrastructure, such as SSH and Kubernetes API access, originate from the following public IPv4 addresses. Add all four to your firewall or API server allowlist.

| Region | Availability zone | IP address |
|---|---|---|
| Europe (Frankfurt) | `eu-central-1a` | `63.183.170.86` |
| Europe (Frankfurt) | `eu-central-1b` | `18.196.66.114` |
| US East (Ohio) | `us-east-2a` | `3.19.214.126` |
| US East (Ohio) | `us-east-2b` | `18.227.187.66` |

As a CIDR list:

```text
63.183.170.86/32
18.196.66.114/32
3.19.214.126/32
18.227.187.66/32
```

Allow every address, not only the ones in the region closest to you. A connection can originate from any of them.

This page is the authoritative list of vCluster Labs egress addresses.
