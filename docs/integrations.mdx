vCluster, vCluster Platform, and vMetal work with the hardware, AI software, and operations tools you already run. This page collects every documented integration in one place, and each card leads to the guide that sets it up. To see what one partner's integrations do together, start with its section, such as [NVIDIA](#nvidia).

Each card names the docs it leads to: **vCluster**, **vCluster Platform**, or **vMetal**. A **Free** or **Enterprise** tag means the integration needs a platform license at that tier. See [Licensing](/docs/platform/next/reference/licensing) for the plans. An **Experimental** tag marks a feature that can change between releases. Tags repeat what each guide states, so a missing tier tag means the guide doesn't state one.

A card means the docs cover setting up that integration. It doesn't state a formal partnership or a certification.

## NVIDIA

NVIDIA integrations cover each layer of a GPU cloud. Use any of them on its own, or combine them:

- **Provision GPU infrastructure** with NVIDIA Infra Controller (NICo) through vMetal.
- **Prepare GPU nodes and collect GPU metrics** with the NVIDIA GPU Operator and DCGM.
- **Create and connect Kubernetes clusters** with NVKE.
- **Schedule and serve workloads** with the KAI scheduler, NVIDIA Run:ai, or NVIDIA Dynamo.
- **Watch GPU health** with the Fleet Intelligence Agent and NVSentinel.

The [NVIDIA DSX OS guide](/docs/platform/next/integrations/nvidia-dsx-os) shows how these pieces fit together on the platform.

## Bare metal and virtual machines

Supply worker nodes, control plane machines, and standalone servers from the hardware and hypervisors you operate.

KubeVirt appears three times, depending on what the virtual machines are for. The node provider creates virtual machines that join a cluster as its worker nodes. Virtual machine management lets administrators run and operate virtual machines from the platform UI. The vCluster integration lets workloads inside a cluster create their own virtual machines.
