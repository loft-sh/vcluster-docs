## 0.38.0

### Upgrade notes

Upgrading to 0.38 is supported only from 0.37. vCluster 0.38 doesn't remove or
rename any `vcluster.yaml` keys. Check these items before you upgrade. Each one
has a required action in [Upgrade from vCluster 0.37 to 0.38](../../operate/upgrade/upgrade-0-37-to-0-38.mdx).

- Clusters on 0.37.0 or 0.37.1 that use the resource proxy start enforcing
  validating admission policies and webhooks on proxied writes. Server-side
  apply to a proxied resource is refused. These checks shipped in 0.37.2.
- Istio 1.27 and 1.28 are no longer tested. The tested versions are 1.29.0,
  1.30.0, and 1.31.1. See [Istio](../../integrations/istio.mdx).
- If vCluster Platform manages your clusters, upgrade it to 5.0 first.

### New features

- **Embedded etcd defragmentation timeout.**
  `controlPlane.backingStore.etcd.embedded.defragTimeout` limits startup
  defragmentation, with a default of `5m`. Set `0s` to skip it. See
  [Embedded etcd](../../configure/control-plane/components/backing-store/etcd/embedded.mdx).
- **Docker driver on Podman.** The Docker driver works with Podman through its
  Docker-compatible API. See
  [Docker container basics](../../deploy/control-plane/docker-container/basics.mdx).
- **Argo CD cluster metadata.** `integrations.argoCD.cluster.metadata` adds
  labels and annotations to the cluster's Argo CD registration.
  {/* Link after #3017 merges. */}
- **Observability integration.** `integrations.observability` delivers the
  Platform metrics-writer Secret to the cluster.

- **ServiceMonitor scrape interval.** `controlPlane.serviceMonitor.interval`
  sets how often Prometheus scrapes the control plane. Also in 0.37.3. See
  [ServiceMonitor](../../configure/control-plane/deployment/service-monitor.mdx).

### Changes

- The default Kubernetes version is 1.36.5, which fixes CVE-2026-2270. The 1.35
  and 1.34 images move to 1.35.9 and 1.34.12. Also in 0.37.4.
- Embedded etcd defragments on startup only when it can reclaim enough space.
  Before 0.38, it defragmented on every start and failed after 30 seconds.
- The control plane sends the upstream API server's own host in the `Host`
  header on proxied requests, so API servers that check the header accept them.
- Auto Nodes removes unscheduled static node claims first when it scales down a
  pool, one claim at a time. It replaces node claims that haven't joined when a
  pool's configuration changes, and removes nodes whose machine is gone. See
  [Auto Nodes](../../configure/private-nodes/auto-nodes.mdx).
- A management backup taken with the CLI includes the platform's identity
  Secrets. Also in 0.37.4.

### Fixes

- `vcluster platform destroy` works against vCluster Platform 5.0. Earlier CLI
  versions stopped before deleting anything. See
  [Uninstall the platform](/docs/platform/next/administer/uninstall).
- Restoring a snapshot of an embedded database keeps the store revision moving
  forward, and the restore refuses to run over a live database.
- `vcluster connect` handles kubeconfig servers without an explicit port, and
  port forwarding drops a path in the kubeconfig server URL.
- Platform node claims work in clusters without Auto Nodes, and a pending node
  claim is deleted when its node pool is removed.
- When a sync fails part way, changes that weren't synced yet are kept instead
  of being overwritten.
- Generic sync propagates a delete on the control plane cluster to the object
  in the cluster.
- Platform sleep mode annotations on Ingresses no longer sync back into nested
  clusters.
- Containerd registry credentials that contain `$` are preserved on private
  nodes.
- Private nodes detect dead konnectivity agent connections.
- A stopping standalone control plane is removed from the Kubernetes endpoints.
- kube-vip keeps the virtual IP and sends ARP while it leads.
- The CLI image downloads kubectl from `dl.k8s.io`.
