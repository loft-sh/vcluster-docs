These pages list every field in `vcluster.yaml`, the configuration file for a cluster created with vCluster. Each page covers one top-level key and gives each field's type, default, and description. The tables are generated from the vCluster configuration schema, so they match the version of the docs you're reading.

To learn how the file is structured and applied, see [What is vcluster.yaml?](../../configure/what-is-vcluster-yaml.mdx). For step-by-step configuration, start in Configure. The vCluster chart's [`values.yaml`](https://github.com/loft-sh/vcluster/blob/main/chart/values.yaml) shows every default, and its [`values.schema.json`](https://github.com/loft-sh/vcluster/blob/main/chart/values.schema.json) validates a `vcluster.yaml` file.

## Top-level keys

| Key | What it configures |
| --- | --- |
| [`controlPlane`](./control-plane.mdx) | Control plane components, such as the Kubernetes distro, backing store, CoreDNS, and proxy, and how the control plane is deployed and exposed. |
| [`deletion`](./deletion.mdx) | Deletion protection and automatic deletion of the cluster. |
| [`deploy`](./deploy.mdx) | Add-on components vCluster deploys into the cluster, such as kube-proxy, a CNI, a CSI driver, MetalLB, metrics server, Argo CD applications, and Stacks. |
| [`experimental`](./experimental.mdx) | Experimental features. Their configuration might change between releases. |
| [`exportKubeConfig`](./export-kube-config.mdx) | How vCluster exports the cluster's kubeconfig, including the context, server, and target Secrets. |
| [`integrations`](./integrations.mdx) | Integrations with tools on the control plane cluster, such as cert-manager, External Secrets Operator, Istio, KubeVirt, metrics server, Netris, and Argo CD. |
| [`logging`](./logging.mdx) | Log encoding and log file output. |
| [`networking`](./networking.mdx) | Service replication, DNS resolution, and other networking options. |
| [`platform`](./platform.mdx) | The connection to vCluster Platform, such as the API key and project. |
| [`plugins`](./plugins.mdx) | Which vCluster plugins to load. |
| [`policies`](./policies.mdx) | Resource quotas, limit ranges, network policies, Pod Security Standards, and central admission control. |
| [`privateNodes`](./private-nodes.mdx) | Private nodes, including kubelet settings, node joining, Auto Nodes, automatic upgrades, and VPN. |
| [`rbac`](./rbac.mdx) | The Role and ClusterRole that vCluster uses on the control plane cluster. |
| [`sleep`](./sleep.mdx) | Automatic sleep and wakeup. |
| [`snapshots`](./snapshots.mdx) | Automatic snapshots. |
| [`sync`](./sync.mdx) | Which resources sync from the cluster to the control plane cluster, and from the control plane cluster into the cluster. |
| [`telemetry`](./telemetry.mdx) | Usage telemetry that vCluster collects. |
