The `deploy` key configures add-on components vCluster deploys into the cluster, such as kube-proxy, a CNI, a CSI driver, MetalLB, a metrics server installed in the cluster, Argo CD applications, and Stacks. For how to configure it, see [Deploy add-ons](../../configure/add-ons/deploy-add-ons.mdx).
