This section holds material you look up rather than read through, such as configuration fields, annotations, supported versions, and terms. The `vcluster` command reference has a section of its own, [CLI](../cli/install.mdx).

To configure a cluster step by step, start in [Configure](../configure/what-is-vcluster-yaml.mdx) instead. Its pages link to the fields they use.

## Configuration and interfaces

- **Configuration fields.** The [vcluster.yaml reference](./vcluster-yaml/overview.mdx) lists every field in `vcluster.yaml` with its type, default, and description, grouped by top-level key.
- **CLI commands.** The [CLI](../cli/install.mdx) section has a page for every vCluster CLI command, with its flags and examples.
- **Annotations and labels.** The [Annotations and labels reference](./annotations.mdx) lists the annotations and labels vCluster uses to identify synced resources.

## Versions and support

- **Supported versions.** The [Lifecycle policy](./lifecycle-policy.mdx) covers the release cadence, supported and LTS releases, feature stages, and the Kubernetes compatibility matrix.
- **Older migrations.** [Loft CLI to vCluster CLI migration](./migrations/loft-cli-vcluster-cli-migration.mdx) maps `loft` commands to `vcluster` commands. [Conversion guide from pre-v0.20 to v0.20](./migrations/0-20-migration.mdx) and [v0.20 CLI updates](./migrations/0-20-cli-changes.mdx) cover the v0.20 breaking changes.

## Terms and docs tools

- **Glossary.** The [Glossary](./glossary.mdx) defines terms used throughout the vCluster docs.
- **Search from an AI assistant.** [Algolia MCP](./algolia-mcp.mdx) connects AI coding assistants that support MCP to the docs search index.
- **Contribute.** [Contribute to vCluster docs](./contribute.mdx) explains how to propose changes to these docs.
