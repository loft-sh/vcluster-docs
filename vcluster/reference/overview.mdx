This section holds the material you look up rather than read through. You come
here with a specific question, such as what a `vcluster.yaml` field defaults to,
which Kubernetes versions a release supports, or what an annotation means. To
configure a cluster step by step, start in
[Configure](../configure/overview.mdx) instead. Its pages link to the
fields they use.

## Generated and hand-written reference

The [vcluster.yaml reference](./vcluster-yaml/overview.mdx) and the
[CLI](../cli/overview.mdx) command pages are generated from the configuration
schema and the CLI's own help on each release, so they cover every field and
every command. The other pages here are written by hand and cover what spans
the product, such as the lifecycle policy, annotations, and the glossary.

## Find what you're looking for

| Looking for | Go to |
|-------------|-------|
| A `vcluster.yaml` field, its type, and its default | [vcluster.yaml reference](./vcluster-yaml/overview.mdx), grouped by top-level key |
| A CLI command and its flags | [CLI](../cli/overview.mdx), with a page for every command |
| An annotation or label on a synced resource | [Annotations and labels](./annotations.mdx) |
| Supported releases, LTS, feature stages, or Kubernetes compatibility | [Lifecycle policy](./lifecycle-policy.mdx) |
| Breaking changes from older releases | [v0.20 migration](./migrations/0-20-migration.mdx), [v0.20 CLI changes](./migrations/0-20-cli-changes.mdx), and [Loft CLI to vCluster CLI](./migrations/loft-cli-vcluster-cli-migration.mdx) |
| A term used in these docs | [Glossary](./glossary.mdx) |
| Docs search from an AI assistant | [Algolia MCP](./algolia-mcp.mdx), for assistants that support MCP |
| How to propose a change to these docs | [Contribute to vCluster docs](./contribute.mdx) |

The Platform API, Platform annotations, and licensing are in the
[vCluster Platform Reference](/docs/platform/reference).
