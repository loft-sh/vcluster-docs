The `privateNodes` section of `vcluster.yaml` configures a cluster whose workloads run on dedicated worker nodes. To choose private nodes and join your first nodes, start with [Private nodes](../../deploy/worker-nodes/private-nodes/overview.mdx) in Deploy. This section covers the settings you tune after that.

- [Auto Nodes](./auto-nodes.mdx): node pools, node type selectors, disruption, and limits for nodes that vCluster Platform provisions on demand.
- [vCluster VPN](./vpn.mdx): connect private nodes to the control plane over a VPN.
- [Default node profile](#default-node-profile): apply a node profile to every node that joins without one.

## Default node profile

Set `privateNodes.defaultProfile` to a [node profile](/docs/platform/next/clusters/node-profiles) name to apply it to any node that joins the <GlossaryTerm term="tenant-cluster">cluster</GlossaryTerm> without an explicit profile:

```yaml title="Set a default node profile"
privateNodes:
  enabled: true
  defaultProfile: general-compute
```

This takes precedence over the project's default node profile, if the project also has one configured. See [Assignment and precedence](/docs/platform/next/clusters/node-profiles#assignment-and-precedence) for the full resolution order.
