This section covers the settings in `vcluster.yaml`, the file that turns a cluster's capabilities on and tunes them. Each category below maps to an area of the file. If you're new to the file, start with [What is vcluster.yaml?](./what-is-vcluster-yaml.mdx), which explains its structure and how a cluster applies it.

## Decide before you deploy

Some settings are fixed when the cluster is created, so set them in the first `vcluster.yaml` you deploy with.

- **Worker nodes.** [Private nodes](./private-nodes/overview.mdx) configures a cluster whose worker nodes are dedicated to it, including Auto Nodes and VPN.
- **Backing store.** [Backing store](./control-plane/components/backing-store/overview.mdx) chooses etcd or a database to hold the cluster's state.

To weigh these choices for production, see [Plan your cluster](../plan/choose-control-plane-deployment.mdx).

## Shape how the cluster works

- **Tune the control plane.** [Control plane](./control-plane/overview.mdx) covers the Kubernetes distribution, CoreDNS, how the control plane is deployed and exposed, and advanced settings.
- **Choose what syncs.** [Resource synchronization](./sync/overview.mdx) decides which resources sync between the cluster and the control plane cluster, and how they change on the way.
- **Connect workloads.** [Networking](./networking/overview.mdx) covers service replication, DNS, Gateway API, and ingress access to the API server.
- **Limit and secure workloads.** [Policies](./policies/overview.mdx) sets resource quotas, limit ranges, network policies, Pod Security Standards, and central admission control.
- **Control access.** [RBAC](./access/rbac.mdx) explains the roles vCluster generates, and [Export kubeconfig](./access/export-kube-config.mdx) customizes the kubeconfig Secret that tools such as Argo CD or Terraform read.

## Automate and extend

- **Automate the lifecycle.** [Auto sleep](./lifecycle/sleep.mdx) pauses idle clusters. [Configure deletion](./lifecycle/deletion.mdx) protects a cluster from deletion or deletes it after inactivity. [Auto snapshots](./lifecycle/snapshots.mdx) back it up on a schedule.
- **Add components.** [Deploy add-ons](./add-ons/deploy-add-ons.mdx) installs components into the cluster at deployment, and [Plugins](./add-ons/plugins.mdx) adds custom sync and other capabilities to vCluster itself.
- **Tune logs and telemetry.** [Log output](./logging-and-telemetry/logging.mdx) switches the control plane between console and JSON logs, and [Telemetry](./logging-and-telemetry/telemetry.mdx) turns usage telemetry to vCluster Labs on or off.
- **Try experimental features.** [Experimental](./experimental/overview.mdx) lists features whose configuration might change between releases.
