The `controlPlane` section of `vcluster.yaml` configures the cluster's control plane. It covers the components, such as the Kubernetes distribution, backing store, CoreDNS, and API server proxy. It also covers how the control plane is deployed and exposed, and advanced settings such as image registries and service accounts.

:::warning Distribution support
Kubernetes (K8s) is the only supported distribution. **K0s** support was removed in vCluster `v0.26` and **K3s** support was removed in `v0.33`. If your clusters still use K3s, see the [K3s to K8s migration guide](../../operate/upgrade/distro-migration.mdx) before upgrading.
:::
