The Proxy feature lets you configure the address and port that the cluster's API server listens on. vCluster uses these fields when generating the certificate for TLS.

## Config reference

| Deprecated Flag | Config Field |
| ----------------- | ---------------- |
| `--bind-address` | `proxy.bindAddress` |
| `--port` | `proxy.port` |
| `--tls-san` | `proxy.extraSANs` |

For every field under `controlPlane.proxy`, see the [`controlPlane` reference](../../../reference/vcluster-yaml/control-plane.mdx#controlPlane-proxy).
