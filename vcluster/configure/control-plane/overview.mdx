The `controlPlane` section of `vcluster.yaml` configures the cluster's control plane. It covers the components, such as the Kubernetes distribution, backing store, CoreDNS, and API server proxy. It also covers how the control plane is deployed and exposed, and advanced settings such as image registries and service accounts.

:::warning Distribution support
Kubernetes (K8s) is the only supported distribution. **K0s** support was removed in vCluster `v0.26` and **K3s** support was removed in `v0.33`. If your clusters still use K3s, see the [K3s to K8s migration guide](../../operate/upgrade/distro-migration.mdx) before upgrading.
:::

## Configure the control plane

- **Components:** the [backing store](./components/backing-store/overview.mdx), [CoreDNS](./components/coredns.mdx), the [Kubernetes distribution](./components/distro/k8s.mdx), the [API server proxy](./components/proxy.mdx), and the [host path mapper](./components/host-path-mapper.mdx).
- **Deployment:** the control plane [StatefulSet](./deployment/statefulset.mdx), [Service](./deployment/service.mdx), [Ingress](./deployment/ingress.mdx), and [ServiceMonitor](./deployment/service-monitor.mdx), plus [CPU and memory limits](./deployment/configure-memory-limits.mdx).
- **Advanced:** the [default image registry](./other/advanced/default-image-registry.mdx), [service accounts](./other/advanced/service-account.mdx), [kube-vip](./other/advanced/kube-vip.mdx), and the [virtual scheduler](./other/advanced/virtual-scheduler.mdx).
