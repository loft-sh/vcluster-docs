By default, this is enabled.

Sync [ConfigMap](https://kubernetes.io/docs/concepts/configuration/configmap/) resources that are used by pods from the cluster to the control plane cluster. Apps frequently need configuration data to function.


### Sync only used ConfigMaps from the tenant to control plane cluster

Sync any ConfigMap that is used by a Pod synced from the tenant to control plane cluster.

```YAML
sync:
  toHost:
    configMaps:
      enabled: true
```

### Sync all ConfigMaps from the tenant to control plane cluster

If you have a resource in the control plane cluster monitoring ConfigMap objects that aren't required by a Pod to run, then you can enable the `all` option.

```YAML
sync:
  toHost:
    configMaps:
      enabled: true
      all: true
```

## Patches

Use `sync.toHost.configMaps.patches` to transform ConfigMap fields while syncing to the control plane cluster. See [Patching synced resources](../../patching/overview.mdx) for syntax, directionality, and examples.
