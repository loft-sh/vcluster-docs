By default, this is enabled.

Sync [Events](https://kubernetes.io/docs/reference/kubernetes-api/cluster-resources/event-v1/) from the control plane cluster to the cluster to be able to view things like pod events from within the cluster. The synced events are associated with cluster resources that are synced to the control plane cluster and provide visibility for vCluster users.

### Disable syncing Events from the control plane cluster to the cluster

```YAML
sync:
  fromHost:
    events:
      enabled: false
```

## Config reference

For every field under `sync.fromHost.events`, see the [`sync` reference](../../../reference/vcluster-yaml/sync.mdx#sync-fromHost-events).
