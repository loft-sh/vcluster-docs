The `sync` section of `vcluster.yaml` controls which resources sync between the cluster and the control plane cluster, in each direction, and how they're transformed on the way. For the concepts behind syncing, see [Resource synchronization](../../overview/resource-synchronization/pod-creation.mdx) in Overview.

- [Sync to the control plane cluster](./to-host/overview.mdx) covers resources created in the cluster, such as Pods, Services, and Ingresses.
- [Sync from the control plane cluster](./from-host/overview.mdx) covers resources the cluster reads from the control plane cluster, such as nodes and storage classes.
- [Patching](./patching/overview.mdx) transforms fields while resources sync.
