:::warning `privateNodes.autoNodes` is deprecated
`privateNodes.autoNodes` in `vcluster.yaml` is deprecated in vCluster v0.38. It still works, and
no removal date is set. For new clusters, use [node pools](/docs/platform/next/vmetal/deploy/node-pools)
instead. A node pool is a platform resource that holds the provider, node types, and network for
a set of a cluster's private nodes. Control plane auto nodes (`controlPlane.standalone.autoNodes`)
aren't deprecated.
:::
