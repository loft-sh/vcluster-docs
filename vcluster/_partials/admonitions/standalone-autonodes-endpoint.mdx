:::note Control plane endpoint
Starting with vCluster Platform 4.13, Platform doesn't publish a `controlPlane.endpoint` for a control plane provisioned through Auto Nodes. The cluster doesn't need one to work.
Platform reaches the control plane over its network peer, and additional control plane nodes and worker nodes join through the first control plane node's address.
For control plane failover on worker nodes, enable `privateNodes.daemon.controlPlaneLoadBalancer`.

Set `controlPlane.endpoint` yourself, before you create the cluster, only when you need a stable address outside Platform:

- Kubeconfigs that bypass Platform.
- TLS for a DNS name or an external load balancer.
- A [kube-vip](../../configure/vcluster-yaml/control-plane/other/advanced/kube-vip.mdx) virtual IP on bare metal. kube-vip requires `controlPlane.endpoint`.

`controlPlane.endpoint` and `privateNodes.daemon.controlPlaneLoadBalancer` are mutually exclusive.
:::
