The vCluster CLI, `vcluster`, creates and manages clusters from your terminal. This section has a reference page for every command, with its flags and examples. Start with [Install the vCluster CLI](./install.mdx) if you don't have it yet.

Commands such as `create`, `list`, and `delete` work through the driver you choose with `vcluster use driver`, which can be Helm, the platform, or Docker. The commands under [`vcluster platform`](./vcluster_platform.md) work with vCluster Platform itself, such as logging in, access keys, sleep, and backups.

## Set up the CLI

- **Install.** [Install the vCluster CLI](./install.mdx) covers macOS, Linux, and Windows.
- **Flags every command takes.** [Global flags](./global-flags.mdx) sets the CLI config file, kube context, namespace, and log verbosity.
- **Use it from kubectl.** [Use vCluster CLI as a kubectl plugin](./cli-kubectl.mdx) sets up the binary so you can run its commands through `kubectl`.
- **Choose a driver.** [`vcluster use driver`](./vcluster_use_driver.md) picks Helm, the platform, or Docker as the way the CLI deploys clusters.
- **Keep it current.** [`vcluster upgrade`](./vcluster_upgrade.md) updates the CLI itself, and [`vcluster version`](./vcluster_version.md) prints the installed version.
- **Telemetry and licenses.** [`vcluster telemetry`](./vcluster_telemetry.md) turns CLI telemetry on or off. [`vcluster credits`](./vcluster_credits.md) saves the license and copyright notices of the CLI's dependencies.

## Create and connect to clusters

- **Create.** [`vcluster create`](./vcluster_create.md) deploys a cluster with the current driver, using a `vcluster.yaml` you pass with `--values`.
- **Connect.** [`vcluster connect`](./vcluster_connect.md) gets you a kubeconfig for a cluster, and [`vcluster disconnect`](./vcluster_disconnect.md) switches your kube context back.
- **Find and inspect.** [`vcluster list`](./vcluster_list.md) lists your clusters, and [`vcluster describe`](./vcluster_describe.md) shows the details of one.
- **Delete.** [`vcluster delete`](./vcluster_delete.md) removes a cluster.

## Run clusters

- **Pause and resume.** [`vcluster pause`](./vcluster_pause.md) stops a cluster and frees its compute, and [`vcluster resume`](./vcluster_resume.md) starts it again.
- **Back up and restore.** [`vcluster snapshot create`](./vcluster_snapshot_create.md) requests a snapshot, [`vcluster snapshot get`](./vcluster_snapshot_get.md) checks it, and [`vcluster restore`](./vcluster_restore.md) restores a cluster from one.
- **Rotate certificates.** [`vcluster certs`](./vcluster_certs.md) checks the control plane certificates and rotates the leaf certificates or the CA.
- **Debug.** [`vcluster debug collect`](./vcluster_debug_collect.md) gathers diagnostic information, and [`vcluster debug shell`](./vcluster_debug_shell.md) opens an ephemeral container in the control plane pod.

## Manage nodes and images

- **Join private nodes.** [`vcluster token`](./vcluster_token.md) creates, lists, and deletes the bootstrap tokens that private nodes use to join a cluster.
- **Maintain nodes.** [`vcluster node`](./vcluster_node.md) upgrades or deletes a node, and loads a local Docker image into one.
- **Move images.** [`vcluster registry`](./vcluster_registry.md) pushes images, archives, and Helm charts into the cluster's registry, saves images as tarballs to import, and proxies the registry for Docker and other tools.

## Work with the platform

- **Platform commands.** [`vcluster platform`](./vcluster_platform.md) holds the commands for vCluster Platform, such as `login`, `access-key`, `sleep`, `wakeup`, and `backup`.
- **Open the UI.** [`vcluster ui`](./vcluster_ui.md) opens the platform web UI.
- **Project secrets.** [`vcluster set secret`](./vcluster_set_secret.md) sets a key in a project or shared secret.
- **Log in and out.** [`vcluster login`](./vcluster_login.md) is deprecated, so use `vcluster platform login` instead. [`vcluster logout`](./vcluster_logout.md) logs out of the platform.

For platform tasks grouped next to their UI equivalents, see the [Platform CLI hub](/docs/platform/next/reference/platform-cli) in the vCluster Platform docs.
