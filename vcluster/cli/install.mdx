The `vcluster` CLI creates, connects to, and manages clusters. It also signs in to vCluster Platform and runs Platform commands through [`vcluster platform`](./vcluster_platform.md).

## Upgrade the CLI

If you installed the CLI with Homebrew, upgrade it with Homebrew so Homebrew keeps track of the installed version:

```bash
brew upgrade loft-sh/tap/vcluster
```

Otherwise, run [`vcluster upgrade`](./vcluster_upgrade.md) to replace the binary with the newest stable release. The command replaces the binary in place, so it needs write access to the directory the binary is in. To install a specific release instead, pass `--version` with the release tag, including the `v` prefix.

<InterpolatedCodeBlock
  code={'vcluster upgrade --version [[VAR:VERSION:v__VCLUSTER_VERSION__]]'}
  language="bash"
/>
