You can either use curl or kubectl to retrieve AppInstances.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


### Retrieve a list of AppInstances
Run the following command to list all AppInstances in project `my-project`:
```bash
kubectl get appinstances.management.loft.sh -n p-my-project -o yaml
```

### Retrieve a single AppInstance by name
Run the following kubectl command to get AppInstance `my-argo-cd` in project `my-project`:
```bash
kubectl get appinstances.management.loft.sh my-argo-cd -n p-my-project -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of AppInstances
Run the following curl command to list all AppInstances in project `my-project`:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/appinstances" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single AppInstance by name
Run the following curl command to get AppInstance `my-argo-cd` in project `my-project`:
```bash
# Exchange my-argo-cd in the url below with the name of the AppInstance
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/appinstances/my-argo-cd" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
