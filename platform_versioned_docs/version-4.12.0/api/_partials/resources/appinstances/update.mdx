### Update AppInstance

Run the following command to update AppInstance `my-argo-cd` in project `my-project`:
```bash
kubectl edit appinstances.management.loft.sh my-argo-cd -n p-my-project
```

Then edit the object and upon save, kubectl will update the resource.

### Patch AppInstance

Patching a resource is useful if you want to generically exchange only a small portion of the object instead of retrieving the whole object first and then modifying it.
To learn more about patches in Kubernetes, please take a look at the [official docs](https://kubernetes.io/docs/tasks/manage-kubernetes-objects/update-api-object-kubectl-patch/#use-a-json-merge-patch-to-update-a-deployment).

Run the following kubectl command to add a new annotation `my-annotation: my-value` to the AppInstance `my-argo-cd` in project `my-project` via a patch:
```bash
kubectl patch appinstances.management.loft.sh my-argo-cd -n p-my-project \
        --type json \
        -p '[{"op": "add", "path": "/metadata/annotations/my-annotation", "value": "my-value"}]'
```

### Update AppInstance

First retrieve the current object into a file `object.yaml`. This could look like:
```yaml
apiVersion: management.loft.sh/v1
kind: AppInstance
metadata:
  creationTimestamp: "2023-04-03T00:00:00Z"
  generation: 12
  name: my-argo-cd
  namespace: p-my-project
  resourceVersion: "66325905"
  uid: af5f9f0f-8ab9-4b4b-a595-a95a5921f3c2
spec:
  destination:
    virtualCluster:
      name: development
      target: vCluster
  displayName: ArgoCD
  owner:
    user: admin
  templateRef:
    name: my-app
status: {}

```

Run the following curl command to update a single AppInstance `my-argo-cd` in project `my-project`:
```bash
# Replace the my-argo-cd in the url below with the name of the AppInstance you want to update
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/appinstances/my-argo-cd" \
     -X PUT --insecure \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY" \
     --data-binary "$(cat object.yaml)"
```

### Patch AppInstance

Patching a resource is useful if you want to generically exchange only a small portion of the object instead of retrieving the whole object first and then modifying it.
To learn more about patches in Kubernetes, please take a look at the [official docs](https://kubernetes.io/docs/tasks/manage-kubernetes-objects/update-api-object-kubectl-patch/#use-a-json-merge-patch-to-update-a-deployment).

Run the following curl command to add a new annotation `my-annotation: my-value` to the AppInstance `my-argo-cd` in project `my-project` via a patch:
```bash
# Replace the my-argo-cd in the url below with the name of the AppInstance you want to update
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/appinstances/my-argo-cd" \
     -X PATCH --insecure \
     -H "Content-Type: application/json-patch+json" \
     -H "Authorization: Bearer $ACCESS_KEY" \
     --data '[{"op": "add", "path": "/metadata/annotations/my-annotation", "value": "my-value"}]'
```
