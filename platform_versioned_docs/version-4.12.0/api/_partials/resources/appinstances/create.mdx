You can either use curl or kubectl to create a new AppInstance.
Make sure to set the project in the `metadata.namespace` field you want to create the AppInstance in. If your project has the id `my-project`, the corresponding namespace would be `p-my-project`.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: AppInstance
metadata:
  name: my-argo-cd
  namespace: p-my-project
spec:
  destination:
    virtualCluster:
      name: development
      target: vCluster
  displayName: ArgoCD
  owner:
    user: admin
  templateRef:
    name: my-app
status: {}

```

Then create the AppInstance `my-argo-cd` in project `my-project` with:
```bash
kubectl create -f object.yaml -n p-my-project
```

  <TabItem value="curl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: AppInstance
metadata:
  name: my-argo-cd
  namespace: p-my-project
spec:
  destination:
    virtualCluster:
      name: development
      target: vCluster
  displayName: ArgoCD
  owner:
    user: admin
  templateRef:
    name: my-app
status: {}

```

Run the following curl command to create a new AppInstance `my-argo-cd` in project `my-project`:
```bash
curl -s -X POST --insecure \
     "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/appinstances" \
     --data-binary "$(cat object.yaml)" \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY"
```
