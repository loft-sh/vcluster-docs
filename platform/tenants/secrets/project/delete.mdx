:::note Tenant users
The platform UI doesn't show project secrets to tenant users, so the following steps are for other users with permission to delete project secrets.
Tenant users can delete project secrets in their own projects through the management API instead.
Connect `kubectl` with `vcluster platform connect management`, then delete the ProjectSecret.
See the [ProjectSecret reference](../../../api/resources/projectsecret.mdx) for the delete command.
:::

<Flow id="secret-delete-project-secret-data">
  <Step>
    Select your project in the project switcher in the sidebar, then click <NavStep>Secrets</NavStep>.
  </Step>
  <Step>
    Open the actions drop-down next to your secret, then click <Label>Delete</Label>.
  </Step>
  <Step>
    Click <Button>Delete</Button> in the confirmation dialog.
  </Step>
</Flow>

Confirm that the secret no longer appears in the project's secret list.
