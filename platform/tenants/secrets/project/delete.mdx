:::note Tenant users
The platform UI hides the **Secrets** menu from tenant users.
The following UI steps are for platform users with permission to delete project secrets.
If you sign in as a tenant user, ask a platform admin to delete the secret for you.
:::

## Delete using the UI

<Flow id="secret-delete-project-secret-data">
  <Step>
    Select your project in the project switcher in the sidebar, then click <NavStep>Secrets</NavStep>.
  </Step>
  <Step>
    Click the <Button>Delete</Button> action for your secret.
  </Step>
  <Step>
    Click <Button>Delete</Button> in the confirmation dialog.
  </Step>
</Flow>

Confirm that the secret no longer appears in the project's secret list.
