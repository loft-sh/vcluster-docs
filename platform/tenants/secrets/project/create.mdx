Project secrets let you define secret data once and share it with your project's namespaces and clusters.

You consume the secret by creating a regular Kubernetes secret with a label that references the project secret. vCluster Platform then synchronizes the data into that secret automatically.

:::note Tenant users
The platform UI hides the **Secrets** menu from tenant users.
The following UI steps are for platform users with permission to create project secrets.
If you sign in as a tenant user, ask a platform admin to create the secret for you.
:::

## Create using the UI

<Flow id="secret-create-project-secret-data">
  <Step>
    Select your project in the project switcher in the sidebar, then click <NavStep>Secrets</NavStep>.
  </Step>
  <Step>
    Click <Button>Create Secret</Button>.
  </Step>
  <Step>
    Enter a display name such as "My Secret" and an optional description. The UI fills in `.metadata.name` automatically; edit the YAML directly to override it.
  </Step>
  <Step>
    In the <Label>Data</Label> section, add your secret key/value pairs.
  </Step>
  <Step>
    Click <Button>Create Project Secret</Button>.
  </Step>
</Flow>

Confirm that the new secret appears in the project's secret list.

See [Sync secrets](../../../use-platform/secrets/secret-sync.mdx) to learn how to use project secret data from a Pod.
