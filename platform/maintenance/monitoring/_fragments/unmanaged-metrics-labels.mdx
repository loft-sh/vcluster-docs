:::note Self-reported labels
This guide's identity labels are added by the collector itself and aren't authenticated by
<GlossaryTerm term="vcluster">vCluster</GlossaryTerm> Platform. They're a different label namespace than Fleet Observability's
`vcluster_platform_*` labels. Dashboards, alerts, and recording rules built for one scheme
return empty results against the other.

Not sure which fleet metrics path fits your situation? See
[Choose a fleet metrics path](../choose-a-fleet-metrics-path.mdx). For the authenticated
label contract, see
[Fleet Observability labels reference](../../observability/labels-reference.mdx).
:::
