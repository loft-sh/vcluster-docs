vMetal networking connects provisioned Machines to the networks they use during provisioning and after they join a tenant cluster. The implementation depends on the selected provisioning driver and network integration.

Network environments group reusable network properties that a driver applies when it creates a Machine. Access to a network environment controls management-plane visibility and consumption. The selected CNI or physical fabric integration provides data-plane connectivity and isolation.

Keep provider-independent network concepts in this section. Use the driver documentation for provider-specific configuration:

- [Configure Metal3 provisioning networks](../drivers/bare-metal/metal3/networking.mdx).
- [Choose a Metal3 network integration](../drivers/bare-metal/metal3/network-integration.mdx).
- [Configure KubeVirt networking](../drivers/virtual-machines/kubevirt.mdx#integrate-with-kube-ovn).
- [Configure NetworkAttachmentDefinitions for virtual Machines](../drivers/virtual-machines/network-attachment-definitions.mdx).

Tenant and Project boundaries determine which network environments a user may consume. They don't replace network isolation inside a tenant cluster or on the underlying physical network.
