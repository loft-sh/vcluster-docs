vCluster Platform is running. These steps take it from a fresh install to a platform your tenants can use. Each step links to the guide that owns the procedure, so skip any you've already done.

1. **Give the platform a domain.** Serve it at your own hostname with TLS, so users and agents reach a stable address. See [Custom domain](../administer/configure/installation-options/domain.mdx).
2. **Set up sign-in.** Connect your identity provider so people sign in with the accounts they already have. See [SSO providers](../administer/authentication/single-sign-on.mdx).
3. **Connect your clusters.** Connect each Kubernetes cluster where cluster control planes should run. See [Connect a cluster](../administer/control-plane-clusters/connect-cluster.mdx).
4. **Add machines, if you run bare metal or VMs.** Connect a vMetal provisioning driver so the platform can provision private nodes and instances. See [Get started with vMetal](../vmetal/get-started.mdx).
5. **Decide who can do what.** Create projects, and add users and teams with the roles they need. See [Create project](../tenants/projects/create.mdx) and [Users, teams, roles, and permissions](../tenants/users-permissions/overview.mdx).
6. **Publish what tenants can create.** Create templates for the clusters, namespaces, and apps you offer. See [Create templates](../tenants/templates/create-templates.mdx).
7. **Create your first cluster.** From a project, create a cluster from one of your templates to confirm that everything works end to end. See [Create a cluster from a template](../use-platform/clusters/create/create-with-template.mdx).
