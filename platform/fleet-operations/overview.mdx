This section is for platform admins who need to see across many clusters at once. It covers fleet-wide metrics and log collection. To monitor the platform's own components, see [Monitoring](../administer/monitoring/overview.mdx) in Administer.

## Collect fleet metrics

- **Start here.** [Fleet Observability](./observability/overview.mdx) is the Platform-managed feature and the default for new deployments. Collectors send metrics through a platform gateway that authenticates writes, adds trusted identity labels, and scopes who can query the results. The [Fleet Observability quickstart](./observability/quickstart.mdx) deploys the default pipeline end to end with Argo CD.
- **When Fleet Observability can't run.** [Monitoring reference architectures](./reference-architectures/fleet-metrics-architectures.mdx) are older, operator-maintained setups that predate Fleet Observability. Use one when the platform runs on embedded Kubernetes, which can't run the observability gateway. A platform with an external database or in multi-region mode runs on embedded Kubernetes. You maintain these setups yourself, and dashboards and alerts built on their labels don't carry over to Fleet Observability.

vCluster Standalone clusters can still use Fleet Observability. Its bundled Argo CD deployment doesn't cover them, so [configure collectors manually](./observability/configure-collectors-manually.mdx).

## Collect logs

Which approach fits depends on where a cluster's pods run.

- **Clusters on private nodes.** Fleet Observability can [collect pod logs](./observability/collect-pod-logs.mdx) and forward them to a logs backend with the cluster's verified identity.
- **Clusters on shared nodes.** [Central HostPath Mapper](./logging/central-hostpath-mapper.mdx) lets log collectors such as Fluentd or Grafana Loki match log files on control plane cluster nodes to the cluster pods that wrote them. One DaemonSet serves every cluster.

For the full comparison, including vCluster Standalone, see [Choose a log collection approach](../administer/logging/overview.mdx#choose-a-log-collection-approach).
