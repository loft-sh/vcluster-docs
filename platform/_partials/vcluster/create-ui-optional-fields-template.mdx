Different options may be configurable on a template, but the following is a list of the main options.

<Flow id="create-vcluster-template-optional-ui">
  <Step>
    <Label>Template Parameters</Label> expose values that users can modify when deploying a cluster from this template.
  </Step>
  <Step>
    <Label>Apps</Label> select applications to install inside the cluster or in its host namespace.
    <Label>Objects</Label> define Kubernetes manifests to create inside the cluster or in its host namespace.
  </Step>
  <Step>
    <Label>Management Access</Label> control who has permission to view or edit this template.
  </Step>
</Flow>
