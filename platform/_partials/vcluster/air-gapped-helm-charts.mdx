:::tip
The platform uses Helm to manage clusters. If your cluster is running in an air-gapped environment, you may host
Helm charts in an OCI compatible private registry. To use a private registry for clusters there are several
configuration options:
- Configure the platform for [offline Helm charts](../../install/air-gapped/with-offline-license-key.mdx#pull-and-push-the-vcluster-helm-chart)
- Configure the Helm chart repository and authentication for each [cluster](../../api/resources/virtualclusterinstance/virtualclusterinstance.mdx).
- Configure the Helm chart repository and authentication using [cluster templates](../../api/resources/virtualclustertemplate.mdx).
:::
