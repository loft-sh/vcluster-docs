:::warning Unset and empty mean opposite things here and on a tenant
Where the project belongs to a tenant, both layers apply and a project member only reaches
what both permit. The two use different mechanisms, so writing "nothing" means opposite
things:

| Layer | Field | Unset or `null` | Empty |
|-------|-------|-----------------|-------|
| Project | <code>{props.field}</code>, a list of names | Everything is allowed | Nothing is allowed |
| Tenant | `allow.byLabels`, a label selector | Nothing is granted | Every admin-owned {props.resource} is granted |

A name list narrows a default of everything. A label selector is a conjunction, so an empty
one is vacuously true and matches every admin-owned {props.resource}.{props.byName ? " A tenant can also grant node types by name with `allow.byName`." : ""} Both follow their own convention, and the
result is that an allow-list set here has no effect on inventory the tenant was never
granted. See [Tenant boundary reference](../../administer/tenants/tenant-boundary-reference.mdx).
:::
