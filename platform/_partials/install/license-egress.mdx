- Allow egress traffic from vCluster Platform pods to https://admin.loft.sh/* (HTTPS, port 443) for license retrieval and usage reporting. Only the platform pods need this. Connected cluster agents and tenant clusters don't contact the license server, so they need no licensing-specific egress. For environments without internet access, see the [air-gapped environment guide](../../install/air-gapped/with-offline-license-key.mdx). For the full model, see [How licensing works](../../understand/licensing.mdx).
