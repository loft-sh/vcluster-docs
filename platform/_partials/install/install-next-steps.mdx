After logging into the UI, you'll be able to start creating clusters immediately. You're automatically part of a [project](../../tenants/concepts/what-are-projects.mdx) called `Default Project`.

Click **New Cluster** and **Create** to spin one up to try out.

:::tip
Find more information about creating clusters in the
[Get started](../../use-platform/overview.mdx#get-started) section of Use the platform.
:::

* [Projects](../../tenants/concepts/what-are-projects.mdx) - How resources can be grouped together into different projects.
* [Clusters](../../overview/vcluster_intro.mdx) - What clusters are and how Platform manages them.
* [Templates](../../tenants/templates/overview.mdx) - How to use templates to control what type of resources that can be made.
* [Connected clusters](../../administer/control-plane-clusters/what-are-clusters.mdx) - How to connect control plane clusters to the platform.
* [Sleep clusters](/docs/vcluster/operate/sleep) - How to pause unused clusters manually or automatically and bring them back up.
