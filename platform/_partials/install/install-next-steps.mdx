After logging into the UI, you'll be able to start creating clusters immediately. You're automatically part of a [project](../../tenants/concepts/what-are-projects.mdx) called `Default Project`.

Click **New Cluster** and **Create** to spin one up to try out.

:::tip
Find more information about creating clusters in the
[create clusters](../../use-platform/clusters/create/create-no-template.mdx) section.
:::

* [Connected clusters](../../administer/control-plane-clusters/what-are-clusters.mdx) - How to connect control plane clusters to the platform.
