After logging into the UI, you'll be able to start creating clusters immediately. You're automatically part of a [project](../../understand/what-are-projects.mdx) called `Default Project`.

Click **New Cluster** and **Create** to spin one up to try out.

:::tip
Find more information about creating clusters in the
[create clusters](../../use-platform/virtual-clusters/create/create-no-template.mdx) section.
:::

* [Tenant clusters](../../introduction/vcluster_intro.mdx) - What tenant clusters are and how Platform manages them.
* [Templates](../../understand/what-are-templates.mdx) - How to use templates to control what type of resources that can be made.
* [Connected clusters](../../understand/what-are-clusters.mdx) - How to connect control plane clusters to the platform.
* [Auto sleep and wakeup](/vcluster/manage/sleep-wakeup) - How to temporarily scale down unused clusters and bring them back up.
