Each namespace created in vCluster Platform belongs to a [project](../../../tenants/concepts/what-are-projects.mdx). Projects control whether users can create namespaces with or without [templates](../../../tenants/templates/what-are-templates.mdx).

## Who can create namespaces without a template

By default, projects require templates for namespace creation. This means:

- **Project users** can only create namespaces from [allowed templates](../../../tenants/projects/allowed/templates.mdx) configured by the project admin.
- **Project admins and platform admins** can always create namespaces without a template, regardless of project settings.

If project admins disable the `requireTemplate` setting, project users can also create namespaces without templates. Keep this setting enabled in production environments to maintain security controls.

## Create without template

:::warning Security consideration

Creating namespaces without a template bypasses the security controls that templates provide. Users with this capability can configure any namespace settings, including [namespace objects](../key-features/isolation.mdx#configure-namespace-objects) and [namespace apps](../../apps/use-in-templates.mdx), which deploy resources directly to the control plane cluster.

For production environments:
- Keep templates required for all projects (the default `requireTemplate` setting).
- Grant project admin roles only to users who need to create namespaces without templates.
- Control who can create projects, since project creators become project admins. See [project membership](../../../tenants/users-permissions/permissions/project.mdx) for details on project roles.

:::
