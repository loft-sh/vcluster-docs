Apps package applications and scripts for reuse. Include Apps in a cluster template to provision clusters with the workloads and supporting services they need.

The template's `apps` field deploys Apps inside the cluster. Its `spaceTemplate.apps` field deploys Apps into the cluster's host namespace on the control plane cluster.

<Flow id="add-app-vcluster-template">
  <Step>
    Go to <NavStep>Tenant Management > Cluster Templates</NavStep> and, if shown, click the <Label>Clusters</Label> tab.
  </Step>
  <Step>
    Edit an existing template, or create a new cluster template.
  </Step>
  <Step>
    Click the <Label>Apps</Label> configuration tab. <br></br>
    <br></br>
    <b>Note: </b>
    the apps defined in this section of the template configuration are apps to
    be deployed *in* the cluster!
  </Step>
  <Step>
    Select an App from the <Label>Please select an App...</Label> selector to include it in the template. You can
    add as many Apps as you like by selecting another. To remove one, click the trash icon next to the App name.
  </Step>
  <Step>
    For each App you added to the template, you can configure the default
    namespace, and any App parameters supplied by the App. For Helm Apps you
    can also configure the Helm release-name.
  </Step>
  <Step>
    To deploy an App into the host namespace, edit the template YAML and add the App to `spec.template.spaceTemplate.apps`. See [Apps and objects](../../tenants/templates/create-templates.mdx#apps-and-objects) for template configuration.
  </Step>
  <Step>
    Finish configuring anything else you'd like on your template, then click
    the
    <Button>Save Changes</Button> button.
  </Step>
</Flow>

## Include Stacks in a cluster template

vCluster v0.37 supports Stacks through `deploy.stacks` in the cluster's `vcluster.yaml`. Use a Stack when applications need dependency ordering, health gates, or output handoff.

Add the Stack in the template's **Stacks** configuration section or YAML. See [Use a Stack](./use-stacks.mdx#choose-how-to-install-a-stack) for the configuration shape. Template authors can also [create a StackTemplate](../../tenants/templates/create-stack-templates.mdx) for users to select.
