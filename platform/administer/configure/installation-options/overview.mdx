Installation options are the content in the [`values.yaml`](../introduction.mdx) except the content under the `config` section and the `agentValues` section.
It contains fields like `resources`, `replicas`, `ingress` and also custom fields like `admin`, `product`, `agentOnly`.

You set values of installation options to customize the deployment of the platform. These installation options are not available in the platform UI after the platform 
is installed in the control plane cluster but can only be [applied using `helm`](../introduction.mdx#applying-configuration) before the deployment.

## Installation modes

Both the platform and the platform agent are installed using the same Helm chart: `vcluster-platform`. The installation mode is controlled by the `agentOnly` value in the `values.yaml`:
```yaml
# false (default): installs the vCluster Platform (control plane).
# true: installs only the vCluster Platform Agent.
agentOnly: false
```
