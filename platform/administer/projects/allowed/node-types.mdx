Allowed node types control which [node types](../../node-providers/overview.mdx) can be referenced by NodeClaims created in a project. Use this to restrict tenants to a subset of the node types available on the platform. For example, you can use this to limit a project to a specific provider or instance class.

:::warning Unset and empty mean opposite things here and on a Tenant
Where the project belongs to a Tenant, both layers apply and a project member only reaches
what both permit. The two use different mechanisms, so writing "nothing" means opposite
things:

| Layer | Field | Unset or `null` | Empty |
|-------|-------|-----------------|-------|
| Project | `allowedNodeTypes`, a list of names | Everything is allowed | Nothing is allowed |
| Tenant | `allow.byLabels`, a label selector | Nothing is granted | Everything is granted |

A name list narrows a default of everything. A label selector is a conjunction, so an empty
one is vacuously true and matches every instance. Both follow their own convention, and the
result is that an allow-list set here has no effect on inventory the Tenant was never
granted. See [Tenant boundary reference](../../tenants/tenant-boundary-reference.mdx).
:::

## Behavior

The project field is `spec.allowedNodeTypes`. Each entry has a `name` that is either an exact node type name (for example, `aws.large`) or a provider wildcard (such as `aws.*`, which matches every node type belonging to provider `aws`).

| Value | Effect |
|-------|--------|
| Unset (field omitted) | All node types are allowed. This is the default. |
| Empty list (`allowedNodeTypes: []`) | No node types are allowed. NodeClaims in the project are rejected. |
| One or more entries | Only allows node types matching any specified entry. |

Matching rules:

- Names are case sensitive.
- The wildcard is only recognized as the suffix `.*`. `aws.*` matches `aws.large` but does not match `awsx.large`.
- The platform rejects a NodeClaim that explicitly references a disallowed node type at creation time.
- For unbound NodeClaims (no `typeRef`), the reconciler filters candidate node types against `allowedNodeTypes` at scheduling time and never assigns a disallowed type to the claim.

Changing `allowedNodeTypes` requires permission to update the project's `allowedNodeTypes` subresource.

## Configure allowed node types

Edit the project and set `spec.allowedNodeTypes`:

```yaml
apiVersion: management.loft.sh/v1
kind: Project
metadata:
  name: team-a
spec:
  allowedNodeTypes:
    - name: aws.*
    - name: metal3.gpu-h100
```

This project can use any node type from the `aws` provider, plus the specific `metal3.gpu-h100` type.

To disallow all node types in a project:

```yaml
spec:
  allowedNodeTypes: []
```
