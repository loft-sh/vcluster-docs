This section holds material you look up rather than read through, such as API resources, annotations, licensing behavior, supported versions, and terms. The management API reference has a section of its own, [API](../api/use-api.mdx).

To set up or run the platform step by step, start in [Administer the management plane](../administer/configure/introduction.mdx) instead. Its pages link to the fields they use.

## Configuration and interfaces

- **Configuration fields.** The [Platform config](../administer/configure/platform-configs/overview.mdx#reference) page lists every field in the `config` section of the platform's `values.yaml`.
- **API resources.** The [API](../api/use-api.mdx) section explains how to call the management API and has a page for every resource it serves.
- **CLI commands.** The [Platform CLI hub](./platform-cli.mdx) groups the platform CLI commands by task, next to their UI equivalents.
- **Annotations and labels.** The [Platform annotations and labels reference](./platform-annotations.mdx) lists the `loft.sh` annotations and labels the platform uses to manage clusters, projects, users, and teams.

## Versions and support

- **Supported versions.** The [Lifecycle policy](./lifecycle-policy.mdx) covers the release cadence, supported and LTS releases, and feature stages.
- **Licensing.** [How licensing works](./licensing.mdx) explains how the platform gets and refreshes its license, how clusters receive licensed features, and what happens when licensing is unavailable.

## Terms and docs tools

- **Glossary.** The [Glossary](./glossary.mdx) defines terms used throughout the platform docs.
- **Search from an AI assistant.** [Algolia MCP](./algolia-mcp.mdx) connects AI coding assistants that support MCP to the docs search index.
- **Contribute.** [Contribute to Platform docs](./contribute.mdx) explains how to propose changes to these docs.

## Covered in other sections

- For the `vcluster.yaml` reference, vCluster annotations and labels, and the full `vcluster` CLI command reference, see [Reference](/docs/vcluster/next/reference) in the vCluster docs.
