A connector configures a platform integration. Platform admins manage connectors; tenants can read a redacted view of connectors assigned to them.

## Connector example

An example Connector:
```yaml
apiVersion: management.loft.sh/v1
kind: Connector
metadata:
  name: shared-postgres
spec:
  displayName: Shared PostgreSQL
  sharedDatabase:
    dialect: postgres
    endpoint: postgres.example.com
    password: replace-with-database-password
    port: "5432"
    user: platform
status: {}

```
