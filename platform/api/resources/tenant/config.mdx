Read or replace a tenant's configuration. A write replaces the entire configuration. Hostname assignments require platform admin permissions.

## TenantConfig example

An example TenantConfig:
```yaml
apiVersion: management.loft.sh/v1
kind: TenantConfig
metadata:
  name: development
spec:
  hostnames:
  - hostname: development.example.com

```
