A Tenant defines which platform resources a tenant may use. Platform admins manage tenant capabilities; the config subresource stores tenant configuration.

## Tenant example

An example Tenant:
```yaml
apiVersion: management.loft.sh/v1
kind: Tenant
metadata:
  name: development
spec:
  displayName: Development
  nodeTypes:
    allow:
      byLabels: null
      byName:
      - my-provider.standard
    enabled: true
status: {}

```
