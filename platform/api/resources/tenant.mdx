A Tenant defines which platform resources a tenant may use, such as control plane clusters, node types, templates, and connectors. Access to tenants is governed by RBAC on the tenants resource. The config subresource stores the tenant's configuration.

## Tenant example

An example Tenant:
```yaml
apiVersion: management.loft.sh/v1
kind: Tenant
metadata:
  name: development
spec:
  displayName: Development
  nodeTypes:
    allow:
      byLabels: null
      byName:
      - my-provider.standard
    enabled: true
status: {}

```
