An OIDCClient configures an application that uses the platform as an OIDC provider.

## OIDCClient example

An example OIDCClient:
```yaml
apiVersion: management.loft.sh/v1
kind: OIDCClient
metadata:
  name: build-service
spec:
  clientId: build-service
  clientSecret: replace-with-client-secret
  name: Build service
  redirectURIs:
  - https://example.com/callback
status: {}

```
