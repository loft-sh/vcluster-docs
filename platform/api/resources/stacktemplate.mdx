StackTemplate is a reusable, parameterized task graph that a StackInstance deploys to a tenant cluster or control plane cluster. See [What are Stacks](../../understand/what-are-stacks.mdx) for the concept and [Create a Stack template](../../administer/templates/create-stack-templates.mdx) for the full task, parameter, and output syntax.

## StackTemplate example

An example StackTemplate:
```yaml
apiVersion: management.loft.sh/v1
kind: StackTemplate
metadata:
  name: example-platform
spec:
  description: Deploys a database before the API that uses it.
  displayName: Example application platform
  tasks:
  - app:
      templateRef:
        name: postgresql
    name: database
  - app:
      templateRef:
        name: example-api
    dependsOn:
    - database
    name: api
status: {}

```
