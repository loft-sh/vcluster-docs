A machine is a read-only mirror of a physical machine in a bare metal provider's inventory. The platform inventory sync manages these objects.

## Machine example

An example Machine:
```yaml
apiVersion: management.loft.sh/v1
kind: Machine
metadata:
  name: metal3.worker-01
spec:
  displayName: worker-01
  providerRef: metal3
status:
  lastSyncTime: null
  phase: Available
  powerState: "Off"

```
