A machine mirrors one physical machine in a bare metal provider's inventory, such as Metal3, NICo, or NetBox through Metal3. The platform inventory sync creates, updates, and deletes machines.

Through this API you can read machines and edit their labels and annotations, for example to assign a machine to a tenant. Creating and deleting machines is refused, and spec, status, and platform-owned labels can't be changed.


## Machine example

An example Machine:
```yaml
apiVersion: management.loft.sh/v1
kind: Machine
metadata:
  name: metal3.worker-01
spec:
  displayName: worker-01
  providerRef: metal3
status:
  lastSyncTime: null
  phase: Available
  powerState: "Off"

```
