A NetworkPeer records a node's addresses, routes, and reachable endpoints.

## NetworkPeer example

An example NetworkPeer:
```yaml
apiVersion: management.loft.sh/v1
kind: NetworkPeer
metadata:
  name: node-a
spec:
  addresses:
  - 198.51.100.10
  allowedIPs:
  - 10.0.0.0/24
  endpoints:
  - 198.51.100.10:41641
status: {}

```
