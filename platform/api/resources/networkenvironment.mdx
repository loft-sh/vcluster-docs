A network environment defines network settings for nodes provisioned through a NodeProvider. Its provider reference is required at creation and cannot be changed.

## NetworkEnvironment example

An example NetworkEnvironment:
```yaml
apiVersion: management.loft.sh/v1
kind: NetworkEnvironment
metadata:
  name: development
spec:
  displayName: Development
  properties: null
  providerRef: my-node-provider
status: {}

```
