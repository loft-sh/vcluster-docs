StackInstance deploys one inline or referenced task graph to a tenant cluster or control plane cluster and reports aggregate and per-task status.

## StackInstance example

An example StackInstance:
```yaml
apiVersion: management.loft.sh/v1
kind: StackInstance
metadata:
  name: example-platform
  namespace: p-my-project
spec:
  destination:
    virtualCluster:
      name: development
  displayName: Example application platform
  owner:
    user: admin
  prunePolicy: Retain
  templateRef:
    name: example-platform
status: {}

```
