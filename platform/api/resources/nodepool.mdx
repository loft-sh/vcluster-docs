A NodePool keeps a set of nodes for one cluster that uses private nodes, all built from one template. A static pool keeps a fixed number of nodes that the platform creates. A dynamic pool hands scaling to Karpenter inside the cluster.

## NodePool example

An example NodePool:
```yaml
apiVersion: management.loft.sh/v1
kind: NodePool
metadata:
  name: compute
  namespace: p-my-project
spec:
  static:
    replicas: 3
  template:
    nodeLabels:
      workload.example.com/tier: compute
    providerRef: my-provider
    requirements:
    - key: vcluster.com/node-type
      operator: In
      values:
      - my-provider.standard
  vClusterRef: my-cluster
status: {}

```
