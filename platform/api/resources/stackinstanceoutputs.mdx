Retrieve the outputs a StackTemplate publishes for a StackInstance. Reading this subresource requires separate `get` permission on `stackinstances/outputs`. See [Stack permissions](../../administer/users-permissions/permissions/stacks.mdx#permission-map) and [What are Stacks](../../understand/what-are-stacks.mdx) for the output-capture concept.

## StackInstanceOutputs example

An example StackInstanceOutputs:
```yaml
apiVersion: management.loft.sh/v1
kind: StackInstanceOutputs
metadata:
  name: example-platform
  namespace: p-my-project
outputs:
- name: databaseAddress
  sensitive: false
  state: Available
  task: database
  value: 10.0.0.12

```
