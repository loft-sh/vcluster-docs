A NodeType describes the resources and scheduling properties of a node offered by a NodeProvider.

## NodeType example

An example NodeType:
```yaml
apiVersion: management.loft.sh/v1
kind: NodeType
metadata:
  name: my-provider.standard
spec:
  displayName: Standard
  machineAllocationPolicy: Assigned
  providerRef: my-provider
  resources:
    cpu: "8"
    memory: 32Gi
status:
  capacity:
    claimed: 0
    total: 0

```
