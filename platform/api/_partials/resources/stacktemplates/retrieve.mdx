You can either use curl or kubectl to retrieve StackTemplates.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},

  <TabItem value="kubectl">


### Retrieve a list of StackTemplates
Run the following command to list all StackTemplates:
```bash
kubectl get stacktemplates.management.loft.sh  -o yaml
```

### Retrieve a single StackTemplate by name
Run the following kubectl command to get StackTemplate `example-platform`:
```bash
kubectl get stacktemplates.management.loft.sh example-platform  -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of StackTemplates
Run the following curl command to list all StackTemplates:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/stacktemplates" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single StackTemplate by name
Run the following curl command to get StackTemplate `example-platform`:
```bash
# Exchange example-platform in the url below with the name of the StackTemplate
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/stacktemplates/example-platform" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
