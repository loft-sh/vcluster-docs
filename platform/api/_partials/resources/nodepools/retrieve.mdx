You can either use curl or kubectl to retrieve NodePools.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


### Retrieve a list of NodePools
Run the following command to list all NodePools in project `my-project`:
```bash
kubectl get nodepools.management.loft.sh -n p-my-project -o yaml
```

### Retrieve a single NodePool by name
Run the following kubectl command to get NodePool `compute` in project `my-project`:
```bash
kubectl get nodepools.management.loft.sh compute -n p-my-project -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of NodePools
Run the following curl command to list all NodePools in project `my-project`:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/nodepools" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single NodePool by name
Run the following curl command to get NodePool `compute` in project `my-project`:
```bash
# Exchange compute in the url below with the name of the NodePool
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/nodepools/compute" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
