### Update NodePool

Run the following command to update NodePool `compute` in project `my-project`:
```bash
kubectl edit nodepools.management.loft.sh compute -n p-my-project
```

Then edit the object and upon save, kubectl will update the resource.

### Patch NodePool

Patching a resource is useful if you want to generically exchange only a small portion of the object instead of retrieving the whole object first and then modifying it.
To learn more about patches in Kubernetes, please take a look at the [official docs](https://kubernetes.io/docs/tasks/manage-kubernetes-objects/update-api-object-kubectl-patch/#use-a-json-merge-patch-to-update-a-deployment).

Run the following kubectl command to add a new annotation `my-annotation: my-value` to the NodePool `compute` in project `my-project` via a patch:
```bash
kubectl patch nodepools.management.loft.sh compute -n p-my-project \
        --type json \
        -p '[{"op": "add", "path": "/metadata/annotations/my-annotation", "value": "my-value"}]'
```

### Update NodePool

First retrieve the current object into a file `object.yaml`. This could look like:
```yaml
apiVersion: management.loft.sh/v1
kind: NodePool
metadata:
  creationTimestamp: "2023-04-03T00:00:00Z"
  generation: 12
  name: compute
  namespace: p-default
  resourceVersion: "66325905"
  uid: af5f9f0f-8ab9-4b4b-a595-a95a5921f3c2
spec:
  static:
    replicas: 3
  template:
    nodeLabels:
      workload.example.com/tier: compute
    providerRef: my-provider
    requirements:
    - key: vcluster.com/node-type
      operator: In
      values:
      - my-provider.standard
  vClusterRef: my-cluster
status: {}

```

Run the following curl command to update a single NodePool `compute` in project `my-project`:
```bash
# Replace the compute in the url below with the name of the NodePool you want to update
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/nodepools/compute" \
     -X PUT --insecure \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY" \
     --data-binary "$(cat object.yaml)"
```

### Patch NodePool

Patching a resource is useful if you want to generically exchange only a small portion of the object instead of retrieving the whole object first and then modifying it.
To learn more about patches in Kubernetes, please take a look at the [official docs](https://kubernetes.io/docs/tasks/manage-kubernetes-objects/update-api-object-kubectl-patch/#use-a-json-merge-patch-to-update-a-deployment).

Run the following curl command to add a new annotation `my-annotation: my-value` to the NodePool `compute` in project `my-project` via a patch:
```bash
# Replace the compute in the url below with the name of the NodePool you want to update
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/nodepools/compute" \
     -X PATCH --insecure \
     -H "Content-Type: application/json-patch+json" \
     -H "Authorization: Bearer $ACCESS_KEY" \
     --data '[{"op": "add", "path": "/metadata/annotations/my-annotation", "value": "my-value"}]'
```
