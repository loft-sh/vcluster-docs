You can either use curl or kubectl to create a new NodePool.
Make sure to set the project in the `metadata.namespace` field you want to create the NodePool in. If your project has the id `my-project`, the corresponding namespace would be `p-my-project`.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: NodePool
metadata:
  name: compute
  namespace: p-default
spec:
  static:
    replicas: 3
  template:
    nodeLabels:
      workload.example.com/tier: compute
    providerRef: my-provider
    requirements:
    - key: vcluster.com/node-type
      operator: In
      values:
      - my-provider.standard
  vClusterRef: my-cluster
status: {}

```

Then create the NodePool `compute` in project `my-project` with:
```bash
kubectl create -f object.yaml -n p-my-project
```

  <TabItem value="curl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: NodePool
metadata:
  name: compute
  namespace: p-default
spec:
  static:
    replicas: 3
  template:
    nodeLabels:
      workload.example.com/tier: compute
    providerRef: my-provider
    requirements:
    - key: vcluster.com/node-type
      operator: In
      values:
      - my-provider.standard
  vClusterRef: my-cluster
status: {}

```

Run the following curl command to create a new NodePool `compute` in project `my-project`:
```bash
curl -s -X POST --insecure \
     "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/nodepools" \
     --data-binary "$(cat object.yaml)" \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY"
```
