
import Tabs from '@theme/Tabs'
import TabItem from '@theme/TabItem'

You can either use curl or kubectl to delete StackInstances.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


Run the following command to delete StackInstance `example-platform` in project `my-project`:
```bash
kubectl delete stackinstances.management.loft.sh example-platform -n loft-p-my-project
```


  </TabItem>
  <TabItem value="curl">


Run the following curl command to delete StackInstance `example-platform` in project `my-project`:
```bash
# Replace the example-platform in the url below with the name of the StackInstance you want to delete
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/loft-p-my-project/stackinstances/example-platform" \
     -X DELETE --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
