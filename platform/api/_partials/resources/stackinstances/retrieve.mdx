You can either use curl or kubectl to retrieve StackInstances.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


### Retrieve a list of StackInstances
Run the following command to list all StackInstances in project `my-project`:
```bash
kubectl get stackinstances.management.loft.sh  -n p-my-project -o yaml
```

### Retrieve a single StackInstance by name
Run the following kubectl command to get StackInstance `example-platform` in project `my-project`:
```bash
kubectl get stackinstances.management.loft.sh example-platform  -n p-my-project -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of StackInstances
Run the following curl command to list all StackInstances in project `my-project`:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/stackinstances" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single StackInstance by name
Run the following curl command to get StackInstance `example-platform` in project `my-project`:
```bash
# Exchange example-platform in the url below with the name of the StackInstance
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/namespaces/p-my-project/stackinstances/example-platform" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```
