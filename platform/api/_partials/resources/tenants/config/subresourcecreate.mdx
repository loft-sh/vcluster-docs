Replace the tenant's entire configuration. Include all settings that should remain configured.

<Tabs
    defaultValue="curl"
    values={[
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="curl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: TenantConfig
metadata:
  name: development
spec:
  hostnames:
  - hostname: development.example.com

```

Then run the following curl command:
```bash
# Exchange development in the url below with the name of the Tenant
curl -s -X POST --insecure \
     "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/tenants/development/config" \
     --data-binary "$(cat object.yaml)" \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY"
```
