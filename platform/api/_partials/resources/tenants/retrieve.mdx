You can either use curl or kubectl to retrieve Tenants.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


### Retrieve a list of Tenants
Run the following command to list all Tenants:
```bash
kubectl get tenants.management.loft.sh -o yaml
```

### Retrieve a single Tenant by name
Run the following kubectl command to get Tenant `development`:
```bash
kubectl get tenants.management.loft.sh development -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of Tenants
Run the following curl command to list all Tenants:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/tenants" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single Tenant by name
Run the following curl command to get Tenant `development`:
```bash
# Exchange development in the url below with the name of the Tenant
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/tenants/development" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
