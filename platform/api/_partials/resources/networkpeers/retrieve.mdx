You can either use curl or kubectl to retrieve NetworkPeers.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


### Retrieve a list of NetworkPeers
Run the following command to list all NetworkPeers:
```bash
kubectl get networkpeers.management.loft.sh -o yaml
```

### Retrieve a single NetworkPeer by name
Run the following kubectl command to get NetworkPeer `node-a`:
```bash
kubectl get networkpeers.management.loft.sh node-a -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of NetworkPeers
Run the following curl command to list all NetworkPeers:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/networkpeers" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single NetworkPeer by name
Run the following curl command to get NetworkPeer `node-a`:
```bash
# Exchange node-a in the url below with the name of the NetworkPeer
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/networkpeers/node-a" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
