
import Tabs from '@theme/Tabs'

You can either use curl or kubectl to delete NodeTypes.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


Run the following command to delete NodeType `my-provider.standard`:
```bash
kubectl delete nodetypes.management.loft.sh my-provider.standard
```


  </TabItem>
  <TabItem value="curl">


Run the following curl command to delete NodeType `my-provider.standard`:
```bash
# Replace the my-provider.standard in the url below with the name of the NodeType you want to delete
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/nodetypes/my-provider.standard" \
     -X DELETE --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
