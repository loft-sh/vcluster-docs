You can either use curl or kubectl to retrieve NodeTypes.

<Tabs
    defaultValue="kubectl"
    values={[

  <TabItem value="kubectl">


### Retrieve a list of NodeTypes
Run the following command to list all NodeTypes:
```bash
kubectl get nodetypes.management.loft.sh -o yaml
```

### Retrieve a single NodeType by name
Run the following kubectl command to get NodeType `my-provider.standard`:
```bash
kubectl get nodetypes.management.loft.sh my-provider.standard -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of NodeTypes
Run the following curl command to list all NodeTypes:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/nodetypes" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single NodeType by name
Run the following curl command to get NodeType `my-provider.standard`:
```bash
# Exchange my-provider.standard in the url below with the name of the NodeType
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/nodetypes/my-provider.standard" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```
