You can either use curl or kubectl to create a new NodeType.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: NodeType
metadata:
  name: my-provider.standard
spec:
  displayName: Standard
  machineAllocationPolicy: Assigned
  providerRef: my-provider
  resources:
    cpu: "8"
    memory: 32Gi
status:
  capacity:
    claimed: 0
    total: 0

```

Then create the NodeType `my-provider.standard` with:
```bash
kubectl create -f object.yaml
```


  </TabItem>
  <TabItem value="curl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: NodeType
metadata:
  name: my-provider.standard
spec:
  displayName: Standard
  machineAllocationPolicy: Assigned
  providerRef: my-provider
  resources:
    cpu: "8"
    memory: 32Gi
status:
  capacity:
    claimed: 0
    total: 0

```

Run the following curl command to create a new NodeType `my-provider.standard`:
```bash
curl -s -X POST --insecure \
     "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/nodetypes" \
     --data-binary "$(cat object.yaml)" \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY"
```
