You can either use curl or kubectl to retrieve Machines.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


### Retrieve a list of Machines
Run the following command to list all Machines:
```bash
kubectl get machines.management.loft.sh -o yaml
```

### Retrieve a single Machine by name
Run the following kubectl command to get Machine `metal3.worker-01`:
```bash
kubectl get machines.management.loft.sh metal3.worker-01 -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of Machines
Run the following curl command to list all Machines:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/machines" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single Machine by name
Run the following curl command to get Machine `metal3.worker-01`:
```bash
# Exchange metal3.worker-01 in the url below with the name of the Machine
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/machines/metal3.worker-01" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
