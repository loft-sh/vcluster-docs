### Update Machine

Run the following command to update Machine `metal3.worker-01`:
```bash
kubectl edit machines.management.loft.sh metal3.worker-01
```

Then edit the object and upon save, kubectl will update the resource.

### Patch Machine

Patching a resource is useful if you want to generically exchange only a small portion of the object instead of retrieving the whole object first and then modifying it.
To learn more about patches in Kubernetes, please take a look at the [official docs](https://kubernetes.io/docs/tasks/manage-kubernetes-objects/update-api-object-kubectl-patch/#use-a-json-merge-patch-to-update-a-deployment).

Run the following kubectl command to add a new annotation `my-annotation: my-value` to the Machine `metal3.worker-01` via a patch:
```bash
kubectl patch machines.management.loft.sh metal3.worker-01 \
        --type json \
        -p '[{"op": "add", "path": "/metadata/annotations/my-annotation", "value": "my-value"}]'
```

### Update Machine

First retrieve the current object into a file `object.yaml`. This could look like:
```yaml
apiVersion: management.loft.sh/v1
kind: Machine
metadata:
  creationTimestamp: "2023-04-03T00:00:00Z"
  generation: 12
  name: metal3.worker-01
  resourceVersion: "66325905"
  uid: af5f9f0f-8ab9-4b4b-a595-a95a5921f3c2
spec:
  displayName: worker-01
  providerRef: metal3
status:
  lastSyncTime: null
  phase: Available
  powerState: "Off"

```

Run the following curl command to update a single Machine `metal3.worker-01`:
```bash
# Replace the metal3.worker-01 in the url below with the name of the Machine you want to update
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/machines/metal3.worker-01" \
     -X PUT --insecure \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY" \
     --data-binary "$(cat object.yaml)"
```

### Patch Machine

Patching a resource is useful if you want to generically exchange only a small portion of the object instead of retrieving the whole object first and then modifying it.
To learn more about patches in Kubernetes, please take a look at the [official docs](https://kubernetes.io/docs/tasks/manage-kubernetes-objects/update-api-object-kubectl-patch/#use-a-json-merge-patch-to-update-a-deployment).

Run the following curl command to add a new annotation `my-annotation: my-value` to the Machine `metal3.worker-01` via a patch:
```bash
# Replace the metal3.worker-01 in the url below with the name of the Machine you want to update
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/machines/metal3.worker-01" \
     -X PATCH --insecure \
     -H "Content-Type: application/json-patch+json" \
     -H "Authorization: Bearer $ACCESS_KEY" \
     --data '[{"op": "add", "path": "/metadata/annotations/my-annotation", "value": "my-value"}]'
```
