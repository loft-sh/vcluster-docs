You can either use curl or kubectl to create a new NetworkEnvironment.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: NetworkEnvironment
metadata:
  name: development
spec:
  displayName: Development
  properties: null
  providerRef: my-node-provider
status: {}

```

Then create the NetworkEnvironment `development` with:
```bash
kubectl create -f object.yaml
```


  </TabItem>
  <TabItem value="curl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: NetworkEnvironment
metadata:
  name: development
spec:
  displayName: Development
  properties: null
  providerRef: my-node-provider
status: {}

```

Run the following curl command to create a new NetworkEnvironment `development`:
```bash
curl -s -X POST --insecure \
     "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/networkenvironments" \
     --data-binary "$(cat object.yaml)" \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
