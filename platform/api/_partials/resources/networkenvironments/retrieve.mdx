You can either use curl or kubectl to retrieve NetworkEnvironments.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


### Retrieve a list of NetworkEnvironments
Run the following command to list all NetworkEnvironments:
```bash
kubectl get networkenvironments.management.loft.sh -o yaml
```

### Retrieve a single NetworkEnvironment by name
Run the following kubectl command to get NetworkEnvironment `development`:
```bash
kubectl get networkenvironments.management.loft.sh development -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of NetworkEnvironments
Run the following curl command to list all NetworkEnvironments:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/networkenvironments" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single NetworkEnvironment by name
Run the following curl command to get NetworkEnvironment `development`:
```bash
# Exchange development in the url below with the name of the NetworkEnvironment
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/networkenvironments/development" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
