You can either use curl or kubectl to retrieve OIDCClients.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


### Retrieve a list of OIDCClients
Run the following command to list all OIDCClients:
```bash
kubectl get oidcclients.management.loft.sh -o yaml
```

### Retrieve a single OIDCClient by name
Run the following kubectl command to get OIDCClient `build-service`:
```bash
kubectl get oidcclients.management.loft.sh build-service -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of OIDCClients
Run the following curl command to list all OIDCClients:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/oidcclients" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single OIDCClient by name
Run the following curl command to get OIDCClient `build-service`:
```bash
# Exchange build-service in the url below with the name of the OIDCClient
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/oidcclients/build-service" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
