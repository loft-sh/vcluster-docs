You can either use curl or kubectl to create a new OIDCClient.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: OIDCClient
metadata:
  name: build-service
spec:
  clientId: build-service
  clientSecret: replace-with-client-secret
  name: Build service
  redirectURIs:
  - https://example.com/callback
status: {}

```

Then create the OIDCClient `build-service` with:
```bash
kubectl create -f object.yaml
```


  </TabItem>
  <TabItem value="curl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: OIDCClient
metadata:
  name: build-service
spec:
  clientId: build-service
  clientSecret: replace-with-client-secret
  name: Build service
  redirectURIs:
  - https://example.com/callback
status: {}

```

Run the following curl command to create a new OIDCClient `build-service`:
```bash
curl -s -X POST --insecure \
     "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/oidcclients" \
     --data-binary "$(cat object.yaml)" \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
