You can either use curl or kubectl to retrieve Connectors.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


### Retrieve a list of Connectors
Run the following command to list all Connectors:
```bash
kubectl get connectors.management.loft.sh -o yaml
```

### Retrieve a single Connector by name
Run the following kubectl command to get Connector `shared-postgres`:
```bash
kubectl get connectors.management.loft.sh shared-postgres -o yaml
```


  </TabItem>
  <TabItem value="curl">


### Retrieve a list of Connectors
Run the following curl command to list all Connectors:
```bash
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/connectors" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```

### Get a single Connector by name
Run the following curl command to get Connector `shared-postgres`:
```bash
# Exchange shared-postgres in the url below with the name of the Connector
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/connectors/shared-postgres" \
     -X GET --insecure \
     -H "Authorization: Bearer $ACCESS_KEY"
```


  </TabItem>
</Tabs>
