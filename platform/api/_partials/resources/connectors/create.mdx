You can either use curl or kubectl to create a new Connector.

<Tabs
    defaultValue="kubectl"
    values={[
      {label: 'kubectl', value: 'kubectl'},
      {label: 'curl', value: 'curl'},
    ]}>
  <TabItem value="kubectl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: Connector
metadata:
  name: shared-postgres
spec:
  displayName: Shared PostgreSQL
  sharedDatabase:
    dialect: postgres
    endpoint: postgres.example.com
    password: replace-with-database-password
    port: "5432"
    user: platform
status: {}

```

Then create the Connector `shared-postgres` with:
```bash
kubectl create -f object.yaml
```


  </TabItem>
  <TabItem value="curl">


Create a file `object.yaml` with the following contents:
```yaml
apiVersion: management.loft.sh/v1
kind: Connector
metadata:
  name: shared-postgres
spec:
  displayName: Shared PostgreSQL
  sharedDatabase:
    dialect: postgres
    endpoint: postgres.example.com
    password: replace-with-database-password
    port: "5432"
    user: platform
status: {}

```

Run the following curl command to create a new Connector `shared-postgres`:
```bash
curl -s -X POST --insecure \
     "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/connectors" \
     --data-binary "$(cat object.yaml)" \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY"
```
