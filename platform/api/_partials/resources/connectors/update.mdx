### Update Connector

Run the following command to update Connector `shared-postgres`:
```bash
kubectl edit connectors.management.loft.sh shared-postgres
```

Then edit the object and upon save, kubectl will update the resource.

### Patch Connector

Patching a resource is useful if you want to generically exchange only a small portion of the object instead of retrieving the whole object first and then modifying it.
To learn more about patches in Kubernetes, please take a look at the [official docs](https://kubernetes.io/docs/tasks/manage-kubernetes-objects/update-api-object-kubectl-patch/#use-a-json-merge-patch-to-update-a-deployment).

Run the following kubectl command to add a new annotation `my-annotation: my-value` to the Connector `shared-postgres` via a patch:
```bash
kubectl patch connectors.management.loft.sh shared-postgres \
        --type json \
        -p '[{"op": "add", "path": "/metadata/annotations/my-annotation", "value": "my-value"}]'
```

### Update Connector

First retrieve the current object into a file `object.yaml`. This could look like:
```yaml
apiVersion: management.loft.sh/v1
kind: Connector
metadata:
  creationTimestamp: "2023-04-03T00:00:00Z"
  generation: 12
  name: shared-postgres
  resourceVersion: "66325905"
  uid: af5f9f0f-8ab9-4b4b-a595-a95a5921f3c2
spec:
  displayName: Shared PostgreSQL
  sharedDatabase:
    dialect: postgres
    endpoint: postgres.example.com
    password: replace-with-database-password
    port: "5432"
    user: platform
status: {}

```

Run the following curl command to update a single Connector `shared-postgres`:
```bash
# Replace the shared-postgres in the url below with the name of the Connector you want to update
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/connectors/shared-postgres" \
     -X PUT --insecure \
     -H "Content-Type: application/yaml" \
     -H "Authorization: Bearer $ACCESS_KEY" \
     --data-binary "$(cat object.yaml)"
```

### Patch Connector

Patching a resource is useful if you want to generically exchange only a small portion of the object instead of retrieving the whole object first and then modifying it.
To learn more about patches in Kubernetes, please take a look at the [official docs](https://kubernetes.io/docs/tasks/manage-kubernetes-objects/update-api-object-kubectl-patch/#use-a-json-merge-patch-to-update-a-deployment).

Run the following curl command to add a new annotation `my-annotation: my-value` to the Connector `shared-postgres` via a patch:
```bash
# Replace the shared-postgres in the url below with the name of the Connector you want to update
curl -s "https://$LOFT_DOMAIN/kubernetes/management/apis/management.loft.sh/v1/connectors/shared-postgres" \
     -X PATCH --insecure \
     -H "Content-Type: application/json-patch+json" \
     -H "Authorization: Bearer $ACCESS_KEY" \
     --data '[{"op": "add", "path": "/metadata/annotations/my-annotation", "value": "my-value"}]'
```
