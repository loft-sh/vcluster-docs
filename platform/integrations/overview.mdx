vCluster Platform connects to the systems around your clusters at every layer. It provisions the bare metal servers and virtual machines that become worker nodes, joins them to your network fabric, and installs AI stacks onto the result. It also plugs into the identity providers, secret stores, pipelines, and observability tools you already run.

Many of these guides live in the section of the docs for the feature they extend, such as vMetal or fleet observability. The cards below link straight to each guide, wherever it lives. To see the integrations for vCluster, vCluster Platform, and vMetal in one place, see [all integrations](/docs/integrations). That page also lists tools that run inside a cluster, such as cert-manager, Istio, and GPU scheduling.

A **Free** or **Enterprise** tag means the integration needs a platform license at that tier. See [Licensing](../reference/licensing.mdx) for the plans. An **Experimental** tag marks a feature that can change between releases. Tags repeat what each guide states, so a missing tag means the guide doesn't state that requirement.

## Bare metal and virtual machine provisioning

Supply worker nodes, control plane machines, and standalone servers from the hardware and hypervisors you operate. These drivers are part of [vMetal](../vmetal/overview.mdx).

KubeVirt appears twice, depending on what the virtual machines are for. The node provider creates virtual machines that join a cluster as its worker nodes. Virtual machine management lets administrators run and operate virtual machines from the platform UI.
