# vCluster docs agent notes

`CLAUDE.md` is canonical for writing, terminology, and style guidance in this
repository. Follow it, not any restatement of it, including a prior version of
this file: terminology in particular has changed more than once, and a copy
here will go stale the next time it does.

The vCluster brand skill is `vcluster-brand` in the `loft-sh/ai-skills` repo,
under `plugins/vcluster-brand`. It covers voice, product naming, positioning,
and diagram standards. Use it for diagrams and for marketing-style copy.

If the brand skill and `CLAUDE.md` disagree on terminology, follow `CLAUDE.md`
for this repository.
